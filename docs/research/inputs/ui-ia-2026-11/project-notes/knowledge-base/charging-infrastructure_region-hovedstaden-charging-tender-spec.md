# Region Hovedstaden – Tender Requirements Specification for EV Charge Points

**Source file:** `Region-Hovedstaden-udbud-af-ladeinfrastruktur.pdf`
**Category:** Charging infrastructure — tender / requirements specification (Bilag 1, Kravspecifikation)
**Original language:** Danish (translated/summarized to English below; proper nouns kept in Danish)
**One-line summary:** Requirements specification (Bilag 1, "Kravspecifikation," case no. 21022202, version 1) issued by Region Hovedstaden (Capital Region of Denmark), Center for Ejendomme (Center for Properties), for the purchase, installation and operation of EV charge points across the region's hospital/property sites, including detailed technical, payment, operational, and a fully worked revenue-sharing pricing model.

## Administrative / Issuing Body
- **Issuer:** Region Hovedstaden (Capital Region of Denmark), Center for Ejendomme (Center for Properties)
- **Case/tender number:** Sagsnummer 21022202
- **Document:** Bilag 1, Kravspecifikation ("Appendix 1, Requirements Specification"), version 1 ("vers. 1")
- **Related appendices referenced:** Bilag 1.1 – Cases (used to answer award criteria); Bilag 1.2 – Regneeksempel på tilbagebetaling til Region Hovedstaden (worked example of repayment to the Region); Kontraktbilag 3, Tilbudsliste (Contract Appendix 3, Price/Tender List, tab "Pristrappe" = "price ladder")

## Scope / Volume
- Region wants additional charge points at its properties as part of green-energy transition.
- **~100 new charge points expected in 2021**; **~300 new charge points total by end of 2024.**
- Mix of charge points dedicated to the Region's own pool cars ("puljebiler") and points available to staff, patients, and relatives (visitors) at Region sites.
- Legal/regulatory compliance requirement: Supplier must comply with **BEK nr. 1037 af 28/05/2021** (Danish Executive Order no. 1037 of 28 May 2021 — governs signage, data and price comparison requirements for charge points); compliance costs (e.g., stickers/labels) borne by supplier.

## 2.1 Technical Requirements for Charge Points (A.2.1.x)
| Code | Requirement |
|---|---|
| A.2.1.1 | All charge points must support **load sharing**, so equal output power can be delivered across multiple connected outlets from the same supplier |
| A.2.1.2 | Must comply with all applicable rules/regulations |
| A.2.1.3 | Each charge point must deliver a minimum output of **11–22 kWh (AC)** [note: source text says "kWh" but this is standard AC power terminology and almost certainly means **kW**, not kWh — this appears to be a typo in the source document, reproduced as written] |
| A.2.1.4 | Charge points must have **IEC 62196-2 "Type 2"** charging outlet, without a fixed/tethered cable; usable by all current and future EVs compatible with this connector type |
| A.2.1.5 | If future EVs cannot use Type 2, supplier must switch to the new connector type at its own expense |
| A.2.1.6 | Supplier must affix info signage/guidance developed jointly with Region Hovedstaden, at supplier's expense |
| A.2.1.7 | No supplier/third-party marketing material on charge points; only supplier's own logo and charging info permitted per agreement. **No digital signage** on/near chargers except a payment display |

## 2.2 Payment Requirements (A.2.2.x / B.2.2.7)
| Code | Requirement |
|---|---|
| A.2.2.1 | Charge points usable by all, per the accessibility requirement in the **AFI directive** (EU Alternative Fuels Infrastructure Directive) |
| A.2.2.2 | Supplier establishes/administers payment services and ensures correct user billing |
| A.2.2.3 | Users pay for charging; **Region Hovedstaden must not bear electricity costs** for charging |
| A.2.2.4 | Solution must include a payment module allowing users to settle directly with supplier via an app (own app required); additional options: credit card, roaming, SMS, etc. |
| A.2.2.5 | App charging requires a user profile storing all info incl. credit card |
| A.2.2.6 | App must show which user group (employee vs. pool car) the user belongs to |
| B.2.2.7 (award criterion, **weight 10%**) | Supplier describes payment options offered via the app beyond credit card; evaluated on number of options and UX intuitiveness; must be at no extra cost to Region H |
| A.2.2.8 | User can pay in full per charging session or via monthly invoicing |
| A.2.2.9 | Payment and payment guidance available in **Danish and English** |
| A.2.2.10 | Supplier ensures all taxes/duties are included in the amount charged to end users; responsible for collection/remittance, incl. compliance with the electricity supplier/utility on tax matters |
| A.2.2.11 | Supplier settles **monthly** with Region H for actual electricity consumed, based on sub-meter reading in the charger, plus refund/rebate sought from **SKAT** (Danish Tax Agency). Settlement must occur **no later than the 15th of the month** for the preceding month |
| A.2.2.12 | Monthly settlement sent as one consolidated statement |
| A.2.2.13 | Monthly settlement must minimum include: charger location address, charger ID number, kWh consumption per charger, amount per charger, total kWh and amount per location, and total refund sought per location |
| A.2.2.14 | **Once yearly** (at annual accounts close), supplier delivers an **auditor-certified annual report** reconciling prior settlements, at supplier's own expense |
| A.2.2.15 | Supplier repays the then-current kWh price to Region H regardless of any user subscription arrangements outside Region H's properties |
| A.2.2.16 | Supplier must seek electricity tax refund for electricity used; refund paid to Region Hovedstaden (Region H does not itself seek refund for EV charging electricity) |

## 2.3 Authority/Regulatory Requirements (A.2.3.x)
- A.2.3.1: Supplier always responsible for obtaining regulatory approvals, incl. for installation, if needed.
- A.2.3.2: Region H sets and controls applicable parking rules/signage on site.
- A.2.3.3: Supplier ensures payment modules and options always comply with applicable law.

## 2.4 Siting and Installation (A.2.4.x)
- Power draw to chargers routed via a distribution cabinet ("fordelingsskab") at the location; Region H designates the cabinet location from which power is drawn.
- Chargers placed per an installation plan ("opsætningsplan") issued by Region H.
- A.2.4.1: Charger placed on cast foundation unless wall-mounted; cost borne by supplier.
- A.2.4.2: Supplier must lay an empty conduit ("tomrør") of **Ø110 mm** from the distribution cabinet and place a pull/draw well ("trækbrønd") after the last-placed charger, unless otherwise agreed with Region H.
- A.2.4.3: Supplier, with Region H, must secure/cordon off any work area during installation/excavation.
- A.2.4.4: Chargers must be protected against fault current via a **Type B HPFI** (RCD/GFCI, Type B residual-current device) circuit breaker.
- A.2.4.5: No equipment mounted on existing buildings etc. without prior agreement with Region H.
- A.2.4.6: Supplier must obtain utility-location info (incl. **LER** — Ledningsejerregistret, the Danish registry of buried utility lines) before excavation/installation; costs borne by supplier.

## 2.5 Operations & Maintenance Requirements (A.2.5.x / B.2.5.10)
- A.2.5.1: If a charger is non-functional, Region H must be notified **within max. 12 hours**, with a description of how the problem will be resolved.
- A.2.5.2: Faulty charger must be replaced/repaired **within max. 24 hours** of the fault report; Region H notified when functional again; all replacement/repair costs borne by supplier.
- A.2.5.3: In emergencies (e.g., vehicle collision), supplier must act **within max. 2 hours** of notification to remove danger to public safety (e.g., cable shielding, cordoning).
- A.2.5.4: Chargers must comply with all applicable rules/regulations.
- A.2.5.5: Supplier must maintain a fault-reporting system (web or mobile-based), available **24 hours a day**, letting users (i) report a faulty charger, (ii) report other problems, (iii) leave comments.
- A.2.5.6: Supplier must insure all chargers/cables against vandalism and vehicle collisions, at supplier's expense.
- A.2.5.7: Chargers must always be fully functional and appear clean/tidy.
- A.2.5.8: Supplier provides online system access for Region H to view chargers by location, ID numbers, and photos (**photos no older than 6 months**).
- A.2.5.9: Region H must be notified before any charger/ID-number changes.
- **B.2.5.10 (award criterion, weight 25%):** Region H will enter a service agreement with supplier for maintenance/replacement. Supplier must describe (non-exhaustive): annual inspection scope, cleaning/signage frequency, response/reaction time for faults, customer-service availability (incl. whether contactable 24/7), service/repair availability & response time, software update process, price list for extra work not covered by the service agreement. Positively weighted: concrete customer-service experience with similarly complex clients; ease, respectfulness, and transparency of customer service.
- A.2.5.11: Email questions from users/Region H answered **within 24 hours** on all working days.
- A.2.5.12: Supplier holds **quarterly** operations/status meetings with Region H covering consumption, maintenance, equipment status, new projects (non-exhaustive).

## 2.6 Documentation Requirements (A.2.6.x)
- A.2.6.1: On delivery, final documentation in Danish or English: (1) technical specifications, (2) operating manual.
- A.2.6.2: All documents delivered electronically in a commonly accessible format (PDF, Word, etc.).

## 2.7 Consumption Data & Online Portal (A.2.7.x / B.2.7.3)
- A.2.7.1: Region H has ongoing online access to charging data and equipment operational status, incl. submitted fault reports.
- A.2.7.2: Supplier delivers an **electronic monthly report** containing at minimum:
  1. Timestamp for each charging session — when the cable was plugged in vs. when charging started
  2. Timestamp for when charging ended vs. when the cable was removed
  3. Duration of charging, and duration equipment was occupied without charging
  4. Per-session data: average charging speed, ability to see speed variation during the session, and kWh count
  5. Operational status documentation per charge point, incl. disruptions and downtime
  6. Which location/charger was used for each session
  7. Ability to filter individual locations and multiple chargers together for a complete consumption overview
  8. User pattern visibility at ID-number level across locations
  9. User pattern visibility for the Region's own vehicles, incl. at ID-number level
- **B.2.7.3 (award criterion, weight 30%):** Positively weighted: reporting format giving Region H staff easy access to key metrics/statistics and enabling their own analyses. Positively weighted: solution perceived as easily accessible, clear, and flexible.
- A.2.7.4: Data stored in an online database with Region H access and **unlimited** ability to create users.

## 2.8 Pricing (Section 2.8) — Detailed Commercial/Revenue-Share Model
Three user groups for pricing purposes:
1. **Eksterne** (External) — private users incl. patients, relatives, tradespeople, taxis, external suppliers, etc.
2. **Medarbejdere** (Employees) — Region H staff, private cars/private use
3. **Puljebiler** (Pool cars) — vehicles used for internal driving

| Code | Requirement |
|---|---|
| A.2.8.1 | Price for all user groups must **never exceed 3.50 DKK per kWh incl. VAT** (applies to supplier's own app/RFID tag only, not third-party charging products) |
| B.2.8.2 (award criterion, **weight 35%**) | Supplier must submit a "pristrappe" (price ladder) showing per-kWh price for each group, within the 3.50 DKK/kWh cap. Lower prices for user groups are weighted positively, but price cannot be lower than the repayment amount owed to Region H (see below). Entered in the "Pristrappe" tab of Kontraktbilag 3, Tilbudsliste |
| A.2.8.3 | All refund related to consumption, and the electricity itself, must be repaid to Region H via monthly settlement (see worked example, Bilag 1.2) |
| A.2.8.4 | Any residual amount after refund and electricity price are repaid is split **50% to supplier / 50% to Region Hovedstaden**; must be shown in the price ladder |
| A.2.8.5 | Price for third-party charging products must not exceed the external-user per-kWh price (set per A.2.8.2) |
| A.2.8.6 | Minimum charge to a user must not exceed the price of 1 kWh |
| A.2.8.7 | Supplier may not charge a fee for charging via its own app/RFID tag, nor for charging at other chargers on Region H's properties |
| A.2.8.8 | Supplier must provide free access to its own app and RFID tag for all users |

### Repayment/Refund Mechanism (Section 2.8 explanatory text + Bilag 1.2 worked example)
- Supplier repays the Region the **currently applicable kWh price**, regardless of user subscription status outside Region H properties.
- **Electricity tax refund rate is set by SKAT (Danish Tax Agency)** and follows SKAT's currently applicable rate.
- **As of document date, this means Region Hovedstaden is owed back:**
  - **1.12 DKK per kWh (incl. VAT)** in refund ("Refusion")
  - **1.00 DKK per kWh (incl. VAT)** for electricity and administration
- Definition of "repayment to Region Hovedstaden": the real electricity price plus administration, repaid per kWh, set at **1.00 DKK/kWh** beyond the refund. If Region H's real electricity price rises, this repayment amount rises correspondingly. **This amount can be adjusted with 3 months' notice.**

### Bilag 1.2 — Fully Worked Numeric Example (explicitly labeled fictional/illustrative prices in the source)
> Source explicitly states: "Priserne der er oplyst til dette eksempel, er fiktive og er ikke gældende/retvisende for, hvilke priser, der skal tilbydes i Tilbudslisten." (The prices given in this example are fictional and not applicable/representative of the prices to be offered in the Tender List.)

**Illustrative per-kWh prices (incl. VAT):**
| User group | Price (DKK/kWh, incl. VAT) |
|---|---|
| Puljebiler (Pool cars) | 2.20 |
| Medarbejdere (Employees) | 2.60 |
| Eksterne (External) | 3.25 |

- **Refusion (refund):** 1.12 DKK incl. VAT (0.89 DKK excl. VAT), "as stated by SKAT"
- **Repayment to Region H beyond refund:** 1.00 DKK/kWh incl. VAT (0.80 DKK excl. VAT)

**Worked monthly example** — total consumption at one site: **4,753 kWh**, split as:
| Group | kWh | Price | Amount (incl. VAT) |
|---|---|---|---|
| Puljebiler | 2,198 kWh | × 2.20 DKK | = 4,835.60 DKK |
| Medarbejdere | 946 kWh | × 2.60 DKK | = 2,459.60 DKK |
| Eksterne | 1,609 kWh | × 3.25 DKK | = 5,229.25 DKK |
| **Total** | 4,753 kWh | — | **= 12,524.45 DKK incl. VAT (10,019.56 DKK excl. VAT)** |

**Region H's repayment calculation:**
- Total charging = 4,753 kWh × 0.80 DKK = **3,802.40 DKK excl. VAT**
- Refund = 4,753 kWh × 0.89 DKK = **4,230.17 DKK excl. VAT**
- Remaining for split between Region H and charge operator: 10,019.56 DKK − 3,802.40 DKK = **6,217.16 DKK excl. VAT** [note: this remaining figure, per A.2.8.4 in the spec, should then be split 50/50 between supplier and Region H — the worked example as extracted does not show that final 50/50 split explicitly, it stops at the "tilbage til fordeling" (remaining for distribution) figure]

**Per-kWh margin split by group (incl. VAT), shown in the example:**
| Group | Price − Repayment | Margin per kWh |
|---|---|---|
| Puljebiler | 2.20 − 1.00 | = 1.20 DKK/kWh |
| Medarbejdere | 2.60 − 1.00 | = 1.60 DKK/kWh |
| Eksterne | 3.25 − 1.00 | = 2.25 DKK/kWh |

## Cases (Bilag 1.1 — Award-Criteria Case Studies, Not Scored by Weight but Qualitatively)
- **Case 1:** Describe how Region H can ensure all vehicles (both single-phase and three-phase) can charge simultaneously if **10 charge points are installed on a 63 amp** supply. Must explain how constant charging is ensured, how consumption changes when a vehicle connects/disconnects, and expectations for load sharing. Max. 3 A4 pages.
- **Case 2:** Describe how Region H can, in future, ensure vehicles that finish charging are moved to free up the charger for others. Max. 3 A4 pages.
- Both cases evaluated on description content; positively weighted if problems/solutions are made clear, and if multiple solutions are described where applicable.

## Relevance Notes for HDEV/Depot Tool (Claude's own framing, not from source)
- This document is a strong reference for **multi-site, multi-user-group charging infrastructure procurement with a metered revenue-sharing/repayment commercial model** — directly useful as a template pattern for depot/fleet charging commercial structuring (cost allocation between host site owner and charge point operator, tax-refund pass-through, tiered per-user-group pricing).
- Technical figures (11–22 kW AC per outlet, Type 2/IEC 62196-2 connector, Type B RCD, Ø110mm conduit, load sharing on shared circuits) are for **light-duty passenger EV charging**, not HD trucks, but the load-sharing/circuit-sizing case study (Case 1: 10 points on 63A) is directly analogous to depot load-management problems at smaller scale.
