Source: Nikiforos-Georgios Zacharof & Georgios Fontaras, *Report on VECTO Technology Simulation Capabilities and Future Outlook*, JRC EUR 28272 EN, 2016, Annex Table 2 (pp. 14–26).

This is a faithful reproduction of the full literature-review table underlying the 2016 JRC/VECTO technology survey (see companion file `vecto-capabilities-and-outlook.md` for the report's narrative, Tables 1/3/4/5, and full reference list — reference numbers below correspond to that file's reference list).

**Notes on fidelity:**
- All numeric effect values, sources, and regions are reproduced exactly as extracted from the source PDF text.
- The "Description" column in the original PDF was formatted as justified body text that wrapped across the table's page-column boundaries; the OCR/text-extraction broke some words at line-wraps (e.g., "downsiz" + "ing", "compan" + "y"). Where a word is clearly reconstructible without adding content, it has been rejoined; where the fragmentation makes a phrase ambiguous, it is left as extracted and flagged.
- "FC" = fuel consumption reduction (i.e., a positive number denotes a fuel consumption *reduction*, unless marked "FE" = fuel economy improvement, which is a distinct metric with the same directional meaning of "better").
- All entries are exactly as tabulated in the source; nothing has been added, extrapolated, or estimated by this assistant.
