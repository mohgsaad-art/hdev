# Vehicle-library schema from the EEA 2024–25 join (draft)

Bob, this is the set of library columns EEA data **can** fill for our 4,603 in-scope
e-trucks, and the set it **cannot**. Coverage % is measured on `truck_vehicles.csv`
(4,603 rows). Provenance classes:

- **registry** — a plain registration field (make, model, category, group).
- **certified measured** — a measured component certification (CertificationMethod = Measured).
- **certified standard values** — generated by VECTO from standard values (Annex Xb etc.).
- **VECTO simulated** — a VECTO simulation output (kWh/km, usable kWh, range).
- **derived** — computed from EEA fields (arithmetic shown where used).

## Columns EEA CANNOT fill

| Library column | Why | What is in EEA |
|---|---|---|
| off-vehicle charging power | **0% filled** for ZEVs (`OffVehicleChargingMaxPower` all empty/0) | nothing |
| battery chemistry | not an EEA field | nothing |
| OEM-declared usable kWh | EEA usable is VECTO-simulated (installed × ~0.855), not the OEM's | simulated only |
| peak / overload power & torque | EEA carries rated / continuous only | `em`/`iepc` rated & max-continuous kW |
| motor efficiency maps | not reported; VECTO generates for standard values | nothing |
| ePTO power (kW) | not an EEA field (only a PTO present flag) | `Transmission_PowerTakeOff` flag |
| tyres beyond the axle table | trailer axle tyres not in the data | own-axle tyres only |
| HVAC system configuration | `Aux_HVAC_SystemConfiguration` **0% filled** → VECTO default per group | nothing |
| capacitor capacitance | `cap_capacitance_f` **0% filled** for these trucks | nothing |

## Mode / ResultType (from VECTO source)

- `ResultType = ResultSuccessPEVType` is the XML `xsi:type` of a successful battery-electric
  (PEV) result row (`ResultWriter.cs` line 103/238). `m:ResultSuccessPEVType` is the **same**
  type carried under the manufacturer-report (MRF) XML namespace alias `m:`; CIF and MRF
  report the identical result. So both values mean "successful PEV simulation result" — they
  are not two different numbers.
- `Mode = Total` is the whole-mission result. The `charge depleting` / `charge sustaining`
  modes only appear for OVC-HEVs (hybrids), which are out of scope. For our trucks the
  energy rows are the `Total` / PEV rows.

Reg. anchor: the output fields are Reg. 2017/2400 Annex IV; the kWh/km reported is the
grid-side electric energy consumption (see `certified_numbers_meaning.md` point 1).
