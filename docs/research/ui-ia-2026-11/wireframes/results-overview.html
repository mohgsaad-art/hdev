Hierarchy rules used on every results page
1 page name (26 px, semibold). 2 one status line with a pass or fail mark (17 px). 3 headline figures: label above (12 px, grey), value (30 px), unit beside it (14 px, grey), one note line below (12 px). 4 sections (17 px) with a one-line subtitle. Tables: text left, numbers right, units in the header not in cells. One decimal rule per column. Pass and fail as a mark plus a word, never colour alone.
