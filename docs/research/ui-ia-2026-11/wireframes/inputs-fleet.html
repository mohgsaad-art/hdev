Fleet

One row for each group of identical vehicles doing the same day. Pick a vehicle, a route, a load, body equipment and a shift for each row.

Holds no depot, weather or price values. Templates open from the cells: there is no Templates page.

First-run state (guided first row): the table starts with one row and a strip above it: "Start from a sample", "Describe your fleet to the assistant", or "Fill one row" (vehicle group, distance per day, stops, return time). Filling it creates the five templates silently, named "Row 1 vehicle" and so on, with sourced standard values. Choices for Bob in Question 4.
